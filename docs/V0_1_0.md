# FormProof v0.1.0 Release Notes

**Release Date:** 2026-09-09

FormProof v0.1.0 is the first public release. It provides a Rust library and CLI for compiling a frozen JSON Schema subset into Groth16 (BN254) circuits, enabling MCP/tool hosts to verify that private JSON data satisfies schema constraints without learning actual field values.

## What's Included

### Core Library (`formproof`)

- **Schema parsing** — JSON Schema v0 subset (≤8 properties, integer/enum/string/bytes32)
- **Circuit compilation** — Schema → Groth16 R1CS circuit with BN254 curve
- **Proving** — Generate zkSNARK proofs from private witness data
- **Verification** — Verify proofs against SHA-256 commitment
- **Proof packages** — Portable JSON bundles with proof + commitment + schema fingerprint

### CLI (`formproof-cli`)

| Command | Description |
|---------|-------------|
| `compile` | Compile schema to proving/verifying keys |
| `prove` | Generate proof from witness JSON |
| `verify` | Verify proof against commitment |
| `info` | Show schema constraints and fingerprint |
| `package-build` | Build portable proof package |
| `package-verify` | Verify package with fingerprint validation |

## Known Limitations

These are intentional v0 scope boundaries:

- **No nested objects or arrays** — Only flat objects with ≤8 properties
- **No regex patterns** — String validation limited to `maxLength`
- **Schema is public** — Only the payload values are private
- **No `$ref` or schema composition** — Each schema is self-contained
- **≤8 enum variants** — Enum cardinality is bounded

## Installation

Add to `Cargo.toml`:

```toml
formproof = { git = "https://github.com/kritarth1107/FormProof", tag = "v0.1.0" }
```

Or clone and build:

```bash
git clone https://github.com/kritarth1107/FormProof
cd FormProof
git checkout v0.1.0
cargo build --release
```

## Quick Start

```rust
use formproof::{FormProofSchema, CompiledSchema, Witness, Proof, verify};

let schema = FormProofSchema::from_json(r#"{
    "type": "object",
    "properties": {
        "amount": { "type": "integer", "minimum": 0, "maximum": 50 }
    },
    "required": ["amount"]
}"#).unwrap();

let compiled = CompiledSchema::compile(schema).unwrap();

let mut witness = Witness::new();
witness.set_u64("amount", 25);

let proof = Proof::create(&compiled, &witness).unwrap();
assert!(verify(&compiled, &proof).unwrap());
```
